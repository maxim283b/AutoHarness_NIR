# Дизайн SQL benchmark

## Назначение и протокол

Benchmark предназначен для сравнения выбора agent harness — внешней схемы работы агента — при замороженной target-модели. В этой задаче реализована только среда: каталог задач, общий SQLite verifier и smoke test прямого harness. Обучение алгоритмов выбора и запуск всех harness намеренно не выполняются.

База локальная и детерминированная. `pilot_sql/data/benchmark.sqlite` содержит шесть таблиц (`customers`, `products`, `orders`, `order_items`, `employees`, `events`) и небольшие фиксированные записи. Все задачи имеют естественное описание, доступную схему, признаки сложности, allowlist операций и скрытый эталонный запрос.

## Разбиение и предотвращение утечки

Есть 60 уникальных задач и 24 группы близких шаблонов. Группа целиком назначается в один split; каждый из четырёх split содержит по 15 задач и все шесть типов SQL. Первый набор из 40 задач явно зафиксирован полем `first_experiment_ids`; held-out не участвует в настройке, обновлении памяти, выборе reward или остановке. См. `splits_manifest.json`; его `dataset_hash` фиксирует каталог.

## Verifier

Для каждого вызова создаётся отдельная временная копия SQLite. Запрос допускается только как одна команда `SELECT` или `WITH`; SQLite authorizer дополнительно запрещает запись, DDL и прочие операции. Progress handler завершает долгие запросы по timeout. Сравнение идёт с вычисленным скрытым эталонным результатом: для задач с `ORDER BY` порядок значим, для остальных строки канонизируются сортировкой. Ответ не содержит эталонный SQL.

Структура результата включает `success`, `error_code`, безопасное общее сообщение, elapsed time и row count. Возможные классы: `empty_query`, `multiple_statements`, `sql_error`, `unsafe_query`, `timeout`, `wrong_result`.

## Воспроизводимость и журнал

Технический smoke verifier использует эталонный callback и потому не является оценкой модели. Реальный agent smoke должен использовать `SQLTaskAdapter`, LM Studio и только публичные поля задачи. Latency сохраняется как диагностическое поле verifier-а, но не входит в reward. Существующие результаты не перезаписываются.

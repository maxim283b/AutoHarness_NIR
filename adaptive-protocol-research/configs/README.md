# Конфигурация

Параметры модели задаются через `OPENAI_API_KEY`, `OPENAI_BASE_URL` и `OPENAI_MODEL`; шаблон находится в `.env.example`. Лимиты и режим задаются CLI `scripts/run_experiment.py`, а полная фактическая конфигурация сохраняется в `results/<run>/config.json`. Файл `.env` не читается автоматически, чтобы не скрывать источник параметров: экспортируйте переменные в окружение перед запуском.

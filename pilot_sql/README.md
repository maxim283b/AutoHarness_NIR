# SQL benchmark для выбора agent harness

Это небольшой воспроизводимый benchmark — набор задач для оценки — для исследования внешней схемы работы агента. Он использует только локальную SQLite, фиксированный seed `20261008` и 60 задач: по 15 в `search`, `validation`, `online` и `held-out`. Первый эксперимент использует 40 идентификаторов из `first_experiment_ids`; held-out остаётся запечатанным до финальной оценки.

Все 60 описаний и эталонных запросов различаются. Задачи сгруппированы в 24 `template_group` — группы близких шаблонов; каждая группа целиком находится в одном split. Каждый split содержит все шесть типов: фильтрацию, группировку/агрегацию, JOIN, подзапросы, оконные функции и даты.

```powershell
python -m pilot_sql.build_data
python -m pytest pilot_sql/tests
python -m pilot_sql.smoke_test
```

`tasks.load_tasks()` — внутренний каталог для benchmark runner. Перед передачей агенту используйте `public_task(task)`: эталонный SQL отсутствует. `verifier.verify()` создаёт временную копию SQLite, применяет authorizer (разрешённые операции SQLite), ограничение времени и сравнение результата. Ошибка структурирована полями `error_code` и `error`, без раскрытия эталона.

Результаты не перезаписываются: smoke test отказывается запускаться при существующем `smoke_results.jsonl`. Полная матрица harness здесь намеренно не запускается; этот пакет подготавливает среду.

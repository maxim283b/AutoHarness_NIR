# Improved AutoSaddler V2: итог эксперимента

## Вопрос и метод

Проверялась совместная модификация AutoSaddler V2: структурированная память рефлексии с выборкой релевантного опыта для следующих итераций и инструкции оптимизатору, направляющие его на обоснованные изменения исходного кода инструментов. H0 — исходный OpenCode; H1 — исходный AutoSaddler V2; H2 — модифицированный AutoSaddler V2. H1 и H2 прошли по шесть итераций оптимизации. Целевой агент — OpenCode 1.19.5 с Qwen3.7 Plus. Использовался заранее зафиксированный SWE-bench Pro V1: 24 train, 16 validation, 40 test. Итоговые оценки получены официальным проверщиком на одних 40 test-задачах.

```text
H0 (общий исходный харнесс)
 ├─ исходный AutoSaddler V2 → H1 → validation → test
 └─ AutoSaddler V2 + память/рефлексия + инструкции об инструментах
                                 → H2 → validation → test
```

## Результаты

| Вариант | Решено на test | Доля | Вызовы целевой модели | Токены целевой модели |
| --- | ---: | ---: | ---: | ---: |
| H0 | 16/40 | 40,0% | 2 157 | 36 615 159 |
| H1 | 15/40 | 37,5% | 1 978 | 33 658 476 |
| H2, альтернативный кандидат | 19/40 | 47,5% | 2 040 | 33 968 088 |

Парное сравнение: H1 минус H0 = −2,5 процентного пункта (3 задачи выиграны, 4 проиграны; точный критерий Мак-Немара p=1,0). Альтернативный H2 минус H0 = +7,5 п.п. (6 выиграны, 3 проиграны; p=0,5078). Альтернативный H2 минус H1 = +10 п.п. (6 выиграны, 2 проиграны; p=0,2891). Парный bootstrap 95% интервал для H2 минус H0: от −7,5 до +22,5 п.п. Ни один результат не подтверждает статистически убедительного улучшения.

## Существенная поправка к протоколу

Замороженный алгоритм выбора H2 выбрал исходный H0: он и кандидат `fa214efe…` набрали по 4/16 на validation, а правило разрешения ничьей оставило исходный вариант. После просмотра validation и первых трёх результатов исходного H2 владелец эксперимента распорядился оценить `fa214efe…` в слоте H2. Это исследовательский результат, а не результат заранее зафиксированного правила выбора. Исходный план и три результата исходного H2 сохранены отдельно и не включены в таблицу. Для альтернативы использованы отдельные ID запуска и каталог; результаты H0 и H1 взяты из первоначального test-прогона. Смешивание результатов исключено проверкой ID задачи, кандидата, модели, роли, порядка, образа проверщика и структуры каждого результата.

## Вывод и ограничения

Совместное изменение механизмов дало рабочий альтернативный кандидат с численно более высоким результатом на этих 40 задачах. Заявлять, что улучшенная рефлексия причинно повысила качество, нельзя: проведён один запуск оптимизации на вариант, целевой агент недетерминирован, а альтернативный H2 выбран после просмотра промежуточных результатов. Замороженный основной анализ H2 должен считать выбранным H0. Для подтверждения эффекта нужны новые независимые запуски с заранее закреплённым правилом выбора.

Машиночитаемые материалы: `plan.json`, `analysis.json`, `paired-40.csv`; полные журналы H1/H2, попытки и официальные ответы проверщика хранятся в родительском каталоге кампании. Повторный анализ: из каталога `swe` выполнить `PYTHONPATH=third_party/AutoSaddler/src python3 -c 'from improved_v2.final_alternative import analyze; analyze()'`.
